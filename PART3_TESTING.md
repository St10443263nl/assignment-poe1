
# HuddleApp – Part 3 Testing

## Testing Overview
JUnit tests were used to verify the Part 3 messaging functionality.

## Features Tested
1. Sent messages are added to the correct array.
2. Disregarded messages are added to the correct array.
3. Stored messages are added to the correct array.
4. Message hashes and message IDs are generated and recorded.
5. The longest stored message can be identified.
6. Messages can be searched using their message ID.
7. Stored messages can be searched using the recipient number.
8. Stored messages can be deleted using their message hash.
9. A full report of stored messages can be generated.

## Test Results
The Maven test suite completed successfully, with 31 tests passing and no failures or errors during the recorded test run.

## Conclusion
The tests verified the main Part 3 messaging features and their expected behaviour.
