
# HuddleApp – Part 3 User Guide

## 1. Starting the Application
Open the HuddleApp project in NetBeans and run Main.java.

## 2. Registering and Logging In
Enter your first name, last name, username, password, and cellphone number when prompted. Log in using your registered username and password.

## 3. Sending Messages
Choose option 1 from the main menu to send messages. Enter the recipient's cellphone number and the message text.

## 4. Managing Messages
Choose one of the following actions:
- Option 1: Send the message.
- Option 2: Disregard the message.
- Option 3: Store the message.

## 5. Stored Messages Menu
Choose option 4 from the main menu to access stored message functions.

The available functions allow users to:
1. Display the sender and recipient of stored messages.
2. Display the longest stored message.
3. Search for a message using its ID.
4. Search for stored messages using a recipient number.
5. Delete a stored message using its message hash.
6. Display a full report of stored messages.

## 6. Exiting the Application
Choose option 3 from the main menu to quit the application.
